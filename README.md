This is a project for CY Tech's software engineering school, that aims to track forest fire behaviour using 2D Cells simulation.
It is merely but a simulation, which is nowhere near accurate to reality, however it can give the general pattern of a fire.

REQUIREMENTS : You need to install a media player on your machine to be able to use our Tutorial feature, you can install VLC for that

if you are on ubuntu/linux you can run on your terminal the run.sh file, by first giving it execution rights, to start the program.
